# OncoPilot 肿瘤住院安全工作台

一个面向医疗 AI 求职展示的轻量可交互产品原型。它借鉴真实住院医生工作流，但不复制医院 HIS，只聚焦“在区患者”和“我的分管患者”两个入口。

## 当前版本

- 2 个核心患者范围：在区患者、我的分管患者
- 8 条完全合成的列表样例，其中 3 条为分管患者
- 在患者列表旁嵌入 AI 今日摘要、资料来源提示、待办勾选和人工核实状态
- 合成患者 A01 可完整演示“新增合成检验报告 → 演示解析 → 生成待办 → 医生核实”
- A01 已包含结构化输入、项目参考答案、错误标签、候选输出合同和可重复评分脚本
- 当前为前端交互演示，不冒充已接入医院系统或真实模型
- 不连接医院系统，不保存、上传或公开真实患者信息

## 本地运行

需要 Node.js `>=22.13.0`。

```bash
npm install
npm run dev
```

检查构建与测试：

```bash
npm run lint
npm test
```

## 安全边界

本项目仅用于作品展示、学习和辅助评测，不可用于真实临床决策。AI 输出不能代替有资质的放疗医师完成治疗决定或最终审核。
