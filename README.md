# OncoPilot 肿瘤住院安全工作台

一个面向医疗 AI 求职展示的可交互产品原型。它使用完全合成病例，演示从病例证据追溯、今日管床、医嘱安全复核、文书交班到质量评测的完整工作流。

## 当前版本

- 5 个可切换工作区：病例输入、患者总览、今日管床、文书与交班、评测看板
- 1 个完全合成的肿瘤科住院病例
- 支持证据抽屉、任务勾选、医嘱安全复核、文书句子采纳与驳回
- 评测数据明确标注为预设演示结果，不冒充真实模型性能
- 不连接医院系统，不保存、上传或公开真实患者信息

## 本地运行

需要 Node.js `>=22.13.0`。

```bash
npm install
npm run dev
```

检查构建与测试：

```bash
npm run lint
npm test
```

## 安全边界

本项目仅用于作品展示、学习和辅助评测，不可用于真实临床决策。AI 输出不能代替有资质的放疗医师完成治疗决定或最终审核。
