# OncoPilot 肿瘤病例整理助手

一个面向医疗 AI 求职展示的轻量可交互作品。它只做一件事：医生第一次接管一名肿瘤相关患者时，把已有资料整理成现病史初稿，并提示还需要向患者补问或核对什么。

## 当前版本

- 单一流程：粘贴资料 → 现病史初稿 + 待补问清单 → 医生核对
- 真实接入火山方舟 Coding Plan 的 `deepseek-v4-flash`
- 现病史初稿可编辑，重要事实绑定资料来源
- 对尚未询问的阴性症状不直接补写，而是生成简短的待补问问题
- 覆盖肿瘤科接管的实体瘤、淋巴瘤和白血病患者，不要求患者是第一次住院
- 不再展示没有实际功能的患者列表或“进入管床”页面
- A01 已包含结构化输入、项目参考答案、错误标签、候选输出合同和可重复评分脚本
- 已完成火山方舟五模型单病例初测；Flash 与 Pro 在 A01 均为100分，Flash更快
- 不连接医院系统；演示版不使用、保存或公开可识别患者信息

## 本地运行

需要 Node.js `>=22.13.0`。

```bash
npm install
npm run dev
```

真实模型调用需在服务端配置 `.env.example` 中列出的火山方舟环境变量；密钥不得提交到仓库或发送到客户端。

检查构建与测试：

```bash
npm run lint
npm test
```

## 安全边界

本项目仅用于作品展示、学习和辅助评测，不可用于真实临床决策。AI 输出不能代替有资质的放疗医师完成治疗决定或最终审核。
