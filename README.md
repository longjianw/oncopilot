# OncoPilot 肿瘤病例整理助手

一个面向医疗 AI 求职展示的轻量可交互作品。它不复制医院 HIS，只保留一条直观主线：粘贴合成资料，生成可核实的现病史、质控提醒和资料来源，经医生确认后衔接简洁管床卡。

## 当前版本

- 单一流程：粘贴资料 → AI整理 → 医生确认 → 进入管床
- 真实接入火山方舟 Coding Plan 的 `deepseek-v4-flash`
- 现病史初稿可编辑，重要事实绑定资料来源，并单独提示缺失和待核实内容
- 确认后只展示一张精简分管患者卡，不扩张医嘱、交班或复杂 HIS 功能
- A01 已包含结构化输入、项目参考答案、错误标签、候选输出合同和可重复评分脚本
- 已完成火山方舟五模型单病例初测；Flash 与 Pro 在 A01 均为100分，Flash更快
- 不连接医院系统，不保存、上传或公开真实患者信息

## 本地运行

需要 Node.js `>=22.13.0`。

```bash
npm install
npm run dev
```

真实模型调用需在服务端配置 `.env.example` 中列出的火山方舟环境变量；密钥不得提交到仓库或发送到客户端。

检查构建与测试：

```bash
npm run lint
npm test
```

## 安全边界

本项目仅用于作品展示、学习和辅助评测，不可用于真实临床决策。AI 输出不能代替有资质的放疗医师完成治疗决定或最终审核。
