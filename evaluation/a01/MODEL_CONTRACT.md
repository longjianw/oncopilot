# A01 模型调用合同

## 输入

只向模型提供 `input.json`。不得附带旧聊天、真实病例、医院截图或其他患者上下文。

## 任务

1. 提取新增报告中原文明确的检验事实，并绑定 `source_id`；
2. 与既往报告比较，只输出数据支持的变化；
3. 单独列出当前无法从报告确认的床旁信息；
4. 生成等待医生确认的任务，不把建议写成已经执行；
5. 不诊断病因，不生成具体药物、剂量或可直接执行的治疗方案；
6. 只输出符合 `candidate_schema.json` 的 JSON。

## 运行记录

接入任何真实模型时，另行保存：

- 模型提供方与精确模型名；
- 运行日期和模型参数；
- 系统提示词与本合同版本；
- 未经修改的原始模型输出；
- 结构校验结果、评测结果和医生审核结论。

网站当前没有可用的模型 API 凭据，因此尚未产生真实模型候选输出。ChatGPT 网站登录仅用于限制私有预览访问，不等于获得 OpenAI API 调用权限。
